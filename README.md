# KSeFBot

Налоговый помощник в Telegram для иностранцев с JDG в Польше: забирает фактуры из KSeF,
ведёт ewidencja przychodów и каждый месяц говорит, сколько и когда платить ZUS и налог.

Это инструмент для самостоятельного расчёта, а не налоговая консультация.

## Что уже есть

- `src/tax/` — расчёт ryczałt: социальный ZUS, взнос на здоровье, аванс налога. Деньги в грошах,
  каждый шаг расчёта сохраняется. Параметры по годам в `rules.ts`.
  **Значения 2026 года — заглушки и не сверены**, поэтому расчёт для пользователей отключён.
- `src/bot/` — бот на grammY: выбор языка (ru/uk), короткий онбординг для листа ожидания,
  команда `/delete` удаляет все данные пользователя.
- `src/db/` и `migrations/` — PostgreSQL: пользователи и ответы онбординга. Миграции применяются
  при старте бота или командой `npm run migrate`. Без `DATABASE_URL` данные хранятся в памяти.
- `src/ksef/` — клиент KSeF 2.0: вход по токену KSeF, список фактур продаж, загрузка XML,
  отправка фактур (сессия); разбор FA(3). Проверяется на тестовой среде МФ workflow «KSeF smoke test».
- `src/tax/ewidencja.ts`, `src/tax/nbp.ts` — ewidencja przychodów: дата дохода, курс NBP с
  предыдущего рабочего дня, нумерация по годам, CSV.
- `src/tax/zusPeriods.ts` — сроки ulga na start и preferencyjny ZUS.
- `schemas/fa3/` — официальная XSD FA(3); тесты проверяют по ней генерируемые фактуры.
- `docs/instrukcja-token.md` — черновик инструкции «как создать токен только на чтение» (ru/uk).

## Запуск

```bash
npm install
cp .env.example .env   # вписать TELEGRAM_BOT_TOKEN
npm run dev
npm test
```

Нужен Node.js 22.6 или новее.

## Секреты

Токен бота хранится только в `.env` (не в git) и в секретах GitHub Actions
(`TELEGRAM_BOT_TOKEN`). Никогда не коммитить токены и доступы к KSeF.
